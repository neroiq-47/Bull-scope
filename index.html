How the strategy decides
  1. 15-minute trend: EMA20 is above EMA50 and the last closed candle closes above EMA20.
  2. 5-minute pullback: in the last 30 minutes, price dipped to the 5-minute EMA20 zone, then a bullish 5-minute candle closed back above it.
  3. Plan: stop sits just below the recent swing low (at least 0.2% away). Target is 2R. Size risks 1% of the £100 allocation, capped at 95% of it.
  4. Fee check: a plan is shown only if estimated round-trip fees leave a net reward-to-risk of at least 1.0.

Connect Kraken (read-only)

Read-only is the first integration. It lets Bull-Scope show your balances. It cannot trade, deposit or withdraw.

Setup steps

  1. Sign in at kraken.com directly. Do not use links from emails or messages.
  2. Open account settings and go to the API section.
  3. Create a new key with Query Funds as the only permission.
  4. Leave every other permission off, especially trading, deposits and withdrawals.
  5. If Kraken offers an IP allowlist, restrict the key to your server's outbound IP.
  6. Store the key and secret as server-side secrets (see the README). Never paste them into this website.
  7. Return here and press Test connection.

Security checklist

  • Bull-Scope never asks for card details, bank logins, exchange passwords or API secrets.
  • The browser holds no Kraken credentials. Balance requests go through the server component.
  • The server accepts only read-only endpoints and calls only Kraken's Balance method.
  • No order, leverage, short or withdrawal code exists in this version.

Bull-Scope is paper-first. No live orders, leverage, shorting or withdrawals. Estimates are labelled as such. Not financial advice.
